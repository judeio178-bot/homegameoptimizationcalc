Sports Team Schedule Profit Optimization

Objective:
Find the optimal number of games for a sports team to maximize profit.

Form Factor:
An interactive interface where the user can set prices and costs, including ticket prices, transportation, surrounding-area growth, food profit, and broadcast money.

$ Gained at Sports Games

  • Food and concession profit
  • Ticket prices / gate receipts
  • Growth in surrounding areas: parking, nearby restaurants, and bars
  • Jersey and merchandise sales
  • TV broadcast rights per game

$ Spent for Teams Per Game

  • Production of food
  • Paying employees and game-day staff
  • Player salaries and luxury tax allocation
  • Stadium maintenance: lawn care, water, AC, and construction fees
  • Merchandise production
  • Player transportation
  • Advertisement and production costs

Factors to Keep in Mind

  • Some games generate more profit: rivalry games, playoff races, summer games, and high-demand opponents.
  • Hot games can create more beverage and food sales.
  • Some games underperform because of bad weather, weak opponents, or too many games in a short period.
  • The model uses diminishing returns because more games can make each game feel less special.

Yankees Modeled Optimal Games

This section uses the research-based Yankees starting values. The model uses calculus to find the number of home games where profit is maximized, then compares that value to the Yankees' actual home schedule.

Calculus Connection: Why We Set P'(g) = 0

In this project, P(g) means total profit when the team plays g home games. The derivative, P'(g), represents marginal profit: how much extra profit the next home game adds.

P(g) = ag² + bg
P'(g) = 2ag + b
Set P'(g) = 0 to find the critical point.

Before the Maximum

P'(g) > 0

Profit is still increasing. Each extra home game adds positive profit.

At the Maximum

P'(g) = 0

The graph has a flat tangent line. This is where profit stops increasing and starts decreasing.

After the Maximum

P'(g) < 0

Profit is decreasing. Extra games hurt profit because attendance drops too much compared to the revenue gained.

Since the profit equation is a downward-opening quadratic, the critical point where P'(g)=0 is a maximum, not a minimum.

Calculus Model

Average attendance is modeled as decreasing when more home games are added:

A(g) = 66,196 − 300g

Total profit multiplies the number of games by the estimated profit from each game:

P(g) = g[((A(g))(115.46) + $1.3M + $410,000) − $3.4M]

Since this is a downward-opening quadratic, the maximum happens where P'(g) = 0.

Profit Equation

Let g = number of home games. The model first estimates attendance, then multiplies game profit by the number of games.

A(g) = 66,196 − 300g
Revenue per fan = ticket/gate + food profit + merch profit
P(g) = g[((A(g))(revenue per fan) + broadcast + special adjustments) − cost]

1. Home Games

81 games

This is the number being optimized. More games add chances to make money, but too many games lower average attendance in the model.

2. Attendance Demand

66,196 fans

This is the starting fan demand before the schedule becomes too crowded.

3. Attendance Drop

300 fans/game

Each added home game lowers expected average attendance because more games creates less demand to attend.

4. Ticket / Gate Revenue

$100.61 per fan

This comes from gate receipts divided by total attendance.

5. Food Profit

$8.85 per fan

This is a conservative estimate based on concession spending and high concession gross margins.

6. Merch Profit

$6.00 per fan

If 100 jerseys are sold for $110 each, each fan spends around this amound on merchandise.

7. Broadcast Revenue

$1.3M/game

This is the estimated media value assigned to each game.

8. Special Game Adjustment

$410,000/game

Factoring in everything, underpreforming games, overpreforming games, games that sell more merch and food, aswell as local buisness growth.

9. Total Per-Game Cost

$3.4M/game

Includes player salary allocation, luxury tax allocation, employees, maintenance, utilities, transportation, ads, and production.
