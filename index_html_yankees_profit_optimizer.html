The Calculus Behind the Bronx Model

The model assumes average attendance decreases as the number of Yankees home games increases:

A(g) = 66,196 − 300g

Profit equals the number of games multiplied by revenue per game minus cost per game:

P(g) = g[((A(g))(115.46) + $1.3M + $410,000) − $3.4M]

Since this creates a downward-opening quadratic, the maximum happens where P'(g) = 0.
